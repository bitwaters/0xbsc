- [P1] 非 Info 响应不带池地址时落为 unresolved，回放无法关联同池 K 线；晚到响应也可能被错误归入新池。`src/gmgn/client.ts:192` 在物理请求开始时绑定已观测池，`src/gmgn/facts.ts:162` 只在响应没有明确池地址时使用绑定值，已有事实不重标。

- [P2] 大批发现事件与物理事实共用 200 个待写名额，单批 300 个候选可能使观察立即停止。`src/research/recorder.ts:68` 将发现事件放入有界队列，每次仅提交一个串行写操作，让正式写入可以穿插；溢出仍显式终止研究，不静默丢弃困难样本。
- [P2] 同 attempt/id/hash、但时刻被改变的重复写未报错。`src/research/storage.ts:134` 现在比较完整 envelope，禁止物理身份漂移。
- [P2] 列表裁剪未标记数据不完整。`src/gmgn/facts.ts:162` 现在输出 ARRAY_TRUNCATED / VALUE_TRUNCATED，回放不能把被裁剪输入当完整事实。
- [P2] socket 空闲超时不保证研究请求的总物理耗时。`src/gmgn/client.ts:192` 为新增研究请求增加 2s 总期限，Quote 不重试；正式已有超时配置不变。
