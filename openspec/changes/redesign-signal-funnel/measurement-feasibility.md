# 阶段 B 测量可行性报告

日期：2026-09-07。结论：**工程报告工具可用，当前主市场基准不可用；阶段 B 整体未通过，不能开始模型选择或最终测试。**

## 已验证的报告契约

`measurement-report` 以单独的 expected 注册账本为分母，observations 缺失不会删掉样本。每个注册样本在 1.3/1.5/2/3 倍目标各出现一次；run、模型、基准轨道、协议、ACTUAL/SIMULATED/DECISION、观察上限分别分组。

合成账本包含7个注册样本：1 TP、1 SL、1 NOT_TOUCHED、1 CENSORED、1 UNKNOWN、1来源不可信、1完全未记录。1.3倍报告分母7，TP/all=1/7，条件率=1/2，基准覆盖5/7，可判定覆盖3/7，缺失成功区间[1/7,5/7]。其他目标未记录结果时仍保留分母，不借用1.3倍结果。

回归验证拒绝重复样本、重复目标、无注册测量、身份/确认坐标漂移、超过期限的有效基准，以及无效基准声称TP。旧卡片60min与新24h不合并；真实确认和模拟确认不合并。无样本明确 NO_REGISTERED_SAMPLES，没有0/0命中率。

市场路径中，完整区间未触达为 NOT_TOUCHED；无已观测触达但记录不完整为 CENSORED；已观测触达却无法排除缺口期间先触另一阈值为 UNKNOWN。先跌后涨维持 SL。时间仅定义观测覆盖，不作为盈利或亏损判断。

## 实际数据的限制

部署记录中的 gmgn-facts-v1 审计与实录字段证据均没有验证 Info 价格来源时间。记录了物理请求/返回时间不等于拥有价格来源时间。当前主市场轨道仍为 UNAVAILABLE / PRICE_SOURCE_TIME_UNVERIFIED，不能达到提案的80%有效基准门。

Quote是模拟执行条件，只能另轨配对同数量卖出；K线可证明周期内区间，不能给Info价格补上可靠时间，也不能证明同根K线内的触达先后。

## 验收边界及后续依赖

3.6仅交付报告工具和可行性结论，不意味着3.1–3.5实时采集/任务恢复已接通。报告验证账本结构和计数，不验证外部输入事实的真实来源，输出固定 promotionCertificate=false。

剩余工程包括完整风险/发布干运行、实时配对采集和执行编排、全链路负载报告、最终run与凭据。主基准支持还需要供应商提供可验证的价格来源时间，或重新审查并版本化测量契约；不能由实现自行用HTTP Date/返回时间代填。方案中的数据阶段允许失败退出，不能把该结论勾选为整个39项完成，也不能据此启用新正式策略。
